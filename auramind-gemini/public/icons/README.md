# PWA Icons

Place your app icons here in the following sizes:

- `icon-192x192.png` (192x192 pixels)
- `icon-384x384.png` (384x384 pixels)
- `icon-512x512.png` (512x512 pixels)

## Requirements

- PNG format
- Transparent or solid background
- Should look good at small sizes
- Include a maskable version for Android adaptive icons

## Generating Icons

You can use these tools to generate all required sizes:

- [PWA Icon Generator](https://tools.crawlink.com/tools/pwa-icon-generator)
- [Favicon.io](https://favicon.io)
- [RealFaviconGenerator](https://realfavicongenerator.net)

## OG Image

Also create an Open Graph image at `public/og-image.png`:
- Size: 1200x630 pixels
- Format: PNG
- Should include app name and tagline
